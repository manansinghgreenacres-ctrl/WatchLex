# WatchLex
WatchLex — A full stack web app to discover random movies and watch together with friends. Built with React, TypeScript, and Tailwind CSS. Powered by the TMDB API.


### Features (so far)
- Random movie generator powered by TMDB API
- Movie poster, rating, and description

### Built With
- React + TypeScript
- Tailwind CSS
- TMDB API

### Coming Soon
- User auth
- Watchlist
- Watch party rooms with real-time sync
